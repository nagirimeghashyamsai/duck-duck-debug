# 🦆 Duck Duck Debug

A free, playful browser game that teaches beginner Python debugging.

## 🎮 Play the game

Open `index.html` in a browser, or visit the GitHub Pages link after publishing.

## ✨ Features

- 12 carefully designed Python debugging levels
- Find the incorrect line and choose the correct fix
- Friendly explanations and hints
- 20 XP for completing each level (earned once per level)
- Unlockable rubber duck outfits
- Progress saved in browser localStorage
- Responsive layout for phones and computers
- No downloads, sign-ins, or paid APIs required to play

## 🛠️ Built with

HTML, CSS and vanilla JavaScript. All code is in `index.html` for easy beginner editing. No React or Python installation needed.

## 🚀 Publish on GitHub Pages

1. Create a new **public** GitHub repository called `duck-duck-debug`.
2. Upload this `index.html` and `README.md` to the **root** of the repo, and commit.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, **main**, **/(root)** and save.
4. When publishing finishes, open `https://YOUR-USERNAME.github.io/duck-duck-debug/`.

## 🔍 Customize

- Change colours at the beginning of `<style>` in `index.html`.
- Edit challenges in the `levels` array near the beginning of `<script>`.
- Add a new level following the same format, and update the level total display if you want to expand beyond twelve.

## 📚 What I learned

- How websites combine HTML, CSS and JavaScript
- How to handle button clicks and update the page
- How game states, levels, scoring, and localStorage work
- How to publish a static website with GitHub Pages

This is an educational beginner project. It does **not** execute Python code; the questions are predefined and verified.
